## Reporting a Vulnerability

We take the security of **Civic AI** seriously. If you suspect you have discovered a security vulnerability in this project, please report it immediately using responsible disclosure guidelines.

### How to Report

**Please DO NOT report security vulnerabilities through public GitHub issues.**

Instead, report vulnerabilities privately by emailing:
📧 **baranish2003@gmail.com**

Please include as much of the following information as possible in your report:
- Type of issue (e.g., SQL injection, XSS, broken authentication, secret exposure).
- Full paths or endpoints affected.
- Detailed step-by-step proof-of-concept (PoC) to reproduce the vulnerability.
- Any potential impact or mitigation strategy you recommend.

### Response & Handling Process

1. **Acknowledgment**: You will receive an acknowledgment of your report within 48 hours.
2. **Investigation**: The maintainers will investigate and verify the vulnerability.
3. **Remediation**: A fix will be developed, tested, and released as quickly as possible.
4. **Disclosure**: Once the fix is deployed, an advisory or release note will credit your responsible disclosure (unless you request to remain anonymous).

Thank you for helping keep Civic AI safe and secure for citizens and municipal organizations!
